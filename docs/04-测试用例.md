# 测试用例（阶段一）

测试分两部分：

- **A. 自动化测试**：`mvn test`，JUnit 5 + MockMvc + 内嵌 MongoDB（`de.flapdoodle.embed.mongo.spring31x`，版本 6.0.5），不依赖本地数据库，用例间自动清库。
- **B. 接口冒烟验证**：对运行中的应用（`mvn spring-boot:run`）发真实 HTTP 请求。

**执行结果汇总**：自动化测试 `Tests run: 48, Failures: 0, Errors: 0, Skipped: 0` → BUILD SUCCESS。

| 测试类 | 用例数 | 结果 |
|---|---|---|
| `ConditionOperatorsTest`（条件算子，纯单元） | 8 | 全通过 |
| `LogicEngineTest`（跳转引擎，纯单元） | 11 | 全通过 |
| `SurveyFlowIntegrationTest`（业务流程集成） | 21 | 全通过 |
| `ApiEndToEndTest`（HTTP 层端到端） | 8 | 全通过 |

> 说明：本机 Maven 本地仓库位于受沙箱保护目录之外，如遇插件下载 `AccessDeniedException`，需在非沙箱模式下运行。
